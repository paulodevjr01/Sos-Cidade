# Sos-Cidade
SOS Cidade é um app de denúncias urbanas criado para ajudar os moradores de Alegrete do Piauí a cuidar da cidade. Com ele, qualquer cidadão pode registrar problemas — como buracos, lixo, queimadas e falhas na iluminação — adicionando uma foto, uma descrição e a localização exata no mapa. As ocorrências ficam organizadas por categoria e status.
